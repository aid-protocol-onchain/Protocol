- (constraint) [ADOPTED ADR-005/D14] Both Solana (SVM) and Ethereum (EVM) chains first-class from v1; smart contracts on both.
- (constraint) [ADOPTED D4] No DAO. Open-source repo, human-managed governance, CI/CD, community PRs core-team-merged.
- (constraint) [ADOPTED D3] Donor-first product; donor transparency is the core value prop.
- (decision) AD: Paradigm = per-chain on-chain core (replicated escrow+ledger) + unified off-chain edge aggregation. Binds: all. Prevents: SVM/EVM teams building divergent fund/identity semantics. Rule: chain-specific code only inside chain adapters; everything above is chain-agnostic over a canonical model.
- (decision) AD: Escrow + proof-gated milestone release (ADR-001). Binds: fund flow. Prevents: direct-payout scam exposure. Rule: funds held on-chain; tranche N+1 unlocks only after AI-verified proof of tranche N; first-tranche size set by requester identity tier.
- (decision) AD: Pause/clawback authority (ADR-001). Binds: every campaign. Prevents: runaway fraud. Rule: a core-team multisig can freeze a campaign and redirect undisbursed funds to another verified campaign for the same disaster.
- (decision) AD: Donor identity = on-chain record is source of truth (PDA on Solana, contract mapping on EVM); off-chain indexer aggregates across wallets AND chains; optional Twitter aggregation layer (ADR-002). Prevents: NFT-as-database, divergent identity per chain. Rule: badges derived from cumulative cross-chain value; no NFT required for data or sharing.
- (decision) AD: Verification = public-identity tiers L1/L2, NO KYC v1 (ADR-004). Prevents: regulatory data-controller load + disaster-zone exclusion. Rule: identity tier sets fund-release generosity; requester identity always public; human core-team sign-off before campaign goes live.
- (decision) AD: Web tier is Cloudflare-only (ADR-006). Binds: all client+edge. Prevents: Next.js / non-CF hosting drift. Rule: Vite+React SPA on Pages; Workers for API/oracle/indexer/image-gen; D1/KV/R2/Queues/Workers AI for data+media+AI.
- (decision) AD: Canonical off-chain model is the integration contract. Binds: all features. Prevents: UI/indexer coupling to raw chain shapes. Rule: indexers normalize SVM+EVM events into one schema in D1; all read APIs serve the canonical model, never raw chain data.
- (decision) AD: Media+AI pipeline. Binds: proof-of-spend. Prevents: unverified/graphic media publication. Rule: proof media lands in R2 via Queues; passes authenticity + moderation (Workers AI candidate, ADR-003 pending) before publish; only a pass emits the on-chain proof signal that can gate release.
- (decision) AD: Stablecoin-preferred settlement (brief Q-D). Binds: token registry. Prevents: victim exposure to volatility. Rule: per-chain curated token allowlist; USDC default settlement asset on both chains; donations normalized to USD-equivalent at donation time for badges/leaderboards.
